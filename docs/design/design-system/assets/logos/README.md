# Logos

The mark is the **held hour**: one `interactive` blue 8 by 8 block held between two square brackets, on a 24px grid (brackets 3 units thick). The week holds one hour for learning.

| File | Use |
|---|---|
| `ltw-mark.svg` | Default. Ink brackets, blue block. On `background` and `layer-01`. |
| `ltw-mark-reverse.svg` | On an `interactive` blue ground: white brackets, ink block. |
| `ltw-mark-mono.svg` | One colour, `currentColor`, for print and single-colour contexts. |

- In the app, brackets take `currentColor` (ink on light, white on dark) and the block stays `interactive`.
- 24px beside the name "Lead the Way" in Plex Sans 600 (14px in the side nav, 16px on marketing pages), with a 10px gap. Minimum size 16px. Clear space 4px.
- The name is always live type; there is no wordmark file.
- Never use IBM's logo or striped letterforms, and never another company's logo.
