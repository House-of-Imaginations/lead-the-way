# Logos

The Lead the Way mark is a 24px square with a white three-step stair (a path, 2.4 stroke, square caps): one small step a week.

- `ltw-mark.svg`: `interactive` blue square. The default, beside the name set in Plex Sans 600 at 14px (side nav) or 16px (marketing header).
- `ltw-mark-mono.svg`: `text-primary` ink square for one-colour contexts and print.

Keep clear space of 8px around the square. Never round it, recolour the stair, or place the blue mark on `interactive`. There is no wordmark file: the name is always live type. It is a concept mark and never appears next to IBM logos.
