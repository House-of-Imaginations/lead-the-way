# Icons

Official Carbon icons from `@carbon/icons` (32px viewBox, single path, no fill set). As `<img>` they render in black (the SVG default fill), their only ink, so on `layer-inverse` or `interactive` grounds inline the SVG instead and fill it with `currentColor`. In code, prefer `LeadTheWay.Icon`, which inlines the same paths.

Size them at 16px in nav, buttons, notifications and tags (12px inside tags), 20px in tiles and modal close, 24 to 32px only on marketing pages. Always pair an icon with a word except in the collapsed side nav rail, where the link keeps a `title`.

Nav mapping: Dashboard `dashboard`, Team AI Agreement `document--tasks`, Sprint plan `calendar`, Courses `education`, Outcomes `chart--column`, Portfolio `portfolio`, Badge `certificate`, Settings `settings`, Help `help`, Sign out `logout`. Privacy notes use `view--off` or `locked`.
