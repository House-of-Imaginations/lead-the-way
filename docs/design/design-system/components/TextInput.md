# TextInput

Carbon field: grey `layer-01` fill, `border-strong` bottom rule, label above, helper or error below.

**Provide:** `id`, `label` (sentence case, no colon), `value`/`defaultValue`, `placeholder` (an example, never the label), `helper`, `invalid` + `error`, `disabled`. `LeadTheWay.TextArea` takes the same props for multi-line answers (reflection, agreement rules).

**Do** write errors that say how to fix it: "Add at least one teammate's email." **Don't** put the label inside the field or use placeholder text for instructions a person needs.
