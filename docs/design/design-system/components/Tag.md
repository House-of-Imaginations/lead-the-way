# Tag

Pill label for state and short metadata. Tags are the only rounded shape in the product (`radius-tag`).

**Provide:** `children` (1 to 3 words), `color` (`gray`, `blue`, `green`), optional `onDismiss` to make it removable (tool chips in the agreement editor).

- `blue` means current or active: Active, Now, Week 4, In progress.
- `green` means finished: Completed, Saved, Output reviewed.
- `gray` is neutral: Draft, Not started, tool names.

**Don't** use a tag as a button, colour a tag red for anything short of an error, or put more than three tags in a row.
