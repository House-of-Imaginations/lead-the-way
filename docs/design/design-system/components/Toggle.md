# Toggle

Switch for settings that apply the moment they change. On is `support-success` green; off is `border-strong` grey.

**Provide:** `label`, optional `description`, `on`/`defaultOn`, `onChange`. With a label it renders as a full settings row with a hairline under it.

Use in Settings and Workspace settings only. **Don't** use a toggle inside a form that has a Save button: use a checkbox there.
