# WhoSeesWhat

A plain table that states, per track, what each other person can see. Used on Home (both tracks) and the master guide.

**Provide:** `rows` (`[{who, team, career}]`).

- Header row on `layer-selected` in 600; 12px by 14px cells; hairlines between rows; first column in 600.
- Write the strongest true statement: "Nothing. Not even that this track exists." Never "limited" or "mostly private".
