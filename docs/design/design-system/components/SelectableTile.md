# SelectableTile

A `layer-01` tile that selects on click and outlines in `border-inverse` with a check.

**Provide:** `title`, `description`, optional `icon`, `selected`/`defaultSelected`, `onChange`.

Use for onboarding choices with a sentence of explanation each (team goals, where AI could help). Lay tiles in a grid with `spacing-01` gaps. Multi-select unless the question says "Pick one".
